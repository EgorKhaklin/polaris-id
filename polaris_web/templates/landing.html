An identity authority anyone can check.

Polaris issues identity credentials signed with ML-DSA-65, keeps their status current, and publishes what a relying party needs to verify them offline, with no Polaris code and no network.

What it does

The engine is the credential: issued here, held by a person, checked by anyone. Everything else on this instance serves that path.

{{ ui.icon('badge-check') }}

Issue

After enrolment, under the authority's ML-DSA-65 key. Two independent implementations must agree before a signature is stored.

{{ ui.icon('shield-check') }}

Verify offline

polaris-verify checks a credential against the authority's published keys, with no Polaris code and no network.

{{ ui.icon('activity') }}

Status, online or stapled

Whether a credential is authoritative right now: the relying-party API, or a short-lived signed status assertion the holder carries.

{{ ui.icon('key-round') }}

Holder keys

A credential can be bound to a key on the holder's device. Changing that key takes its own signature.

{{ ui.icon('wallet') }}

Wallets

Copies for OpenID4VCI wallets. polaris-oid4vp 1.0.0rc7 is OpenID Certified to the OpenID4VP 1.0 + HAIP 1.0 Verifier profile; Polaris as a whole is not certified.

{{ ui.icon('eye-off') }}

Zero-knowledge mode

Issuer-unlinkable proofs of a valid credential. What a relying party can correlate is bounded, not eliminated.

{{ ui.icon('anchor') }}

Transparency

Anchored batches, append-only logs and anonymity epochs, published so the authority's record can be checked rather than trusted.

{{ ui.icon('network') }}

Federation

Trust between authorities is explicit, signed, and never transitive.

What it is not yet

Stated here because it is true, and because a claim this page cannot back would cost more than it gains.

  • {{ ui.icon('circle-x') }}Not piloted, not deployed, and not production-ready.
  • {{ ui.icon('circle-x') }}Never held real identity data; this instance runs on notional records.
  • {{ ui.icon('circle-x') }}No independent security review yet.
  • {{ ui.icon('circle-x') }}Algorithm agility under an audited migration path, not settled security against a quantum adversary.

The readiness ledger is the bound on what Polaris may claim.
