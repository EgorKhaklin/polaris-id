SQL Console

A read-only query interface against this deployment's database. A query runs as polaris_console_reader, a database role that holds SELECT on the tables listed below and on nothing else. It cannot read TokenLifecycleEvent, VerificationEvent, AuthAuditLog or DuressEvent. The pages that return rows of those four tables record each read in AuditAccessLog: {% for page in audited_pages %}{{ page }}{{ ', ' if not loop.last else '.' }}{% endfor %}

Other tables that hold one person's or one credential's rows, among them Individual, IdentityToken, EnrollmentStatusEvent, HolderKeyEvent and RecoveryRequest, are outside that record: no AuditAccessLog row records a read of them. This console reads none of them, and none of the count tables (the population, enrolment and activity roll-ups): a cell of them can be a single event. The Atlas reads them and withholds a small count.

Each runs as a subquery of one SELECT in a read-only transaction, so a second statement or a data-modifying WITH is refused.
