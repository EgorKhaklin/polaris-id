What a warrant can read

Only verifications that named one of the person’s credentials: every full disclosure, and a selective disclosure that named its credential. Each is returned with the credential, the verifier and the place it was recorded.

A zero-knowledge verification never stored which credential it checked, so it cannot be attributed to this person, and no warrant returns it.

Read in the database by uc7_warrant_audit; the query is recorded in AuditAccessLog.
