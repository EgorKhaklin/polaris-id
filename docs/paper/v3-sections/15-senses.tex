\section{The assurance layer: how the system notices its own errors}
\label{sec:senses}

\motif{A green test is not proof that the test asked the right question.}

\analogy{The town's own inspectors test the wall by pulling out a stone to see whether the alarm rings; an alarm nobody has ever heard ring is not trusted.}

\subsection{Formal truth is not intended truth}

A check can be green while proving the wrong proposition. A signature can exist without being
verified; a benchmark can count database writes as verifications; a two-witness guarantee can rest on
one witness that happened to be absent; a suite that proves one active credential per person can be
the thing violating it. The assurance layer exists because every layer of this map is believed on the
word of a check, and the checks are written by the same hand as the code they judge. Its question is
not \emph{does it pass} but \emph{would it notice}.

The layer works as a loop (Figure~\ref{fig:senses-loop}): an observation made by running the system
rather than reading it, a failure that is a green check proving the wrong thing, a corrected
statement of what the mechanism proves, an invariant with a detection test, and continuous
integration carrying that invariant on every push. Invariants accumulate and are not deleted.

\subsection{The observers}

No single observer decides whether a claim holds. Each is built differently, so that a mistake one
of them shares with the code is unlikely to be shared by all of them.

\begin{itemize}
  \item \emph{Invariant checks.} Plain functions over the tree, each paired with a detection test
    that shows it passing on a good fixture and failing on a broken one, so a check that cannot see
    its own violation is itself a failure.
  \item \emph{Mutation drills.} Twelve drills remove or invert what a layer relies on (a check, a
    constraint, a trigger, a procedure's refusal, a verifier's rejection, a witness's comparison) and
    require something to go red. A survivor is a guarantee nothing was testing; the few that are
    tolerated are declared with a reason.
  \item \emph{Independent witnesses.} A cryptographic verdict has two implementations and a
    published corpus; the zero-knowledge proof has a second witness written separately. Their
    independence is in implementation, not in their reading of the specification
    (Section~\ref{sec:privacy}).
  \item \emph{Drills and attacks.} Paths are run end to end rather than inspected, and attacks use
    the real code; a fuzzer explores the inputs the drills did not choose.
  \item \emph{The suites under a different axis.} The same suites run as the role production
    connects as rather than the schema owner, under the real signer rather than the development
    placeholder, and from sessions in other timezones, because a suite pinned to one condition
    certifies only that condition.
  \item \emph{Outside observers.} A wallet someone else wrote and a conformance service someone else
    runs. They form a separate layer because every observer inside the repository inherits the
    author's model of what a correct artifact contains; an outside wallet exposed a certificate
    defect that every internal instrument had passed.
\end{itemize}

The same layer holds the vocabulary to the evidence. Checks refuse the stronger word on every
outward surface: the system is described by algorithm agility under an audited migration path, not
by a post-quantum claim; the duress mechanism is duress-aware, not compulsion-resistant; C3 is one
active credential per enrolment identity, not one per human.

\begin{layercard}{Layer card: the assurance layer}
\qa{What it is}{Invariant checks with detection tests, twelve mutation drills, independent
cryptographic witnesses, end-to-end drills, an attack harness, a fuzzer, the suites run under the
production role, the real signer and foreign timezones, and the outside observers on the scoreboard.}
\qa{Why it exists}{Every other layer is believed because a check says so, and a check can be green
while proving the wrong proposition.}
\qa{What it trusts}{That observers built differently do not share the same mistake; that continuous
integration runs what the gate names.}
\qa{What it refuses}{One observer's verdict as sufficient; a check without a detection test; a skipped
security test in continuous integration; a stronger word than the evidence supports.}
\qa{What it can see}{Whatever its observers exercise: a refusal that can be removed without anything
going red, a check that passes on a broken fixture, a suite that holds only for the schema owner.}
\qa{What it cannot see}{A mistake every observer shares, which is why the outside observers matter and
why most of this layer is still written by one author (Section~\ref{sec:limitations}).}
\qa{If it fails}{A guarantee in another layer becomes a belief nobody is testing; the record of each
time that happened is \evidencerecord.}
\qa{Now or later}{Now, inside the repository; outside, one wallet and one conformance service so far.}
\qa{Inside and outside}{Inside: every other layer of this map. Outside: the external observers on
the scoreboard.}
\end{layercard}
