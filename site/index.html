[ Why now ]

Proof before power.

The strongest AI can attack as well as defend, and it can pass for a person. The idea is simple. Any door can set one rule: no token, no entry. A Polaris token is issued to a person, never to a program; a program that acts for a person carries that person's signed, limited grant. Each door sets how much it asks, from a zero-knowledge proof to full disclosure, and anyone can verify the answer on the spot, without surveillance: a bank, a government, a frontier lab, a website.
